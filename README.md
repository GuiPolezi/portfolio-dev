## Como Rodar Localmente

```bash
# Clone o repositório
git clone https://github.com/GuiPolezi/portfolio-dev.git

# Acesse a pasta do projeto
cd portfolio-dev

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev
```

Acesse em: `http://localhost:5173`
